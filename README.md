A newspaper front page that sums up Tuesday 17 November 2026 in one image: the Kerch Bridge down, US strikes on Iran, the Trump-Xi-Putin summit in China, and the rest of the day's world news — masthead, lead story, nine secondary stories, a world map, the day in figures and more stories. The image is drawn entirely in code (own PNG writer, own bitmap font, own drawing code) by the program in `main.ts`, which writes `/output/entry.png`.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
